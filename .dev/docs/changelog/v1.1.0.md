## System › Outline Theme

The theme now has its own settings, modelled on ChatGPT/Codex _Settings › Appearance_:

- **Appearance**: mode (System / Light / Dark), theme presets (Outline, ChatGPT and the Codex collection), accent / background / foreground with a colour picker, fonts, UI / content / code font sizes, contrast, reduce motion, and separate light and dark themes. Copy a theme as an `outline-theme-v1:` string, or import one (Codex `codex-theme-v1:` strings work too).
- **Branding**: pick the logo (Outline, OpenWrt or your own) and one app icon; every favicon and home-screen size is generated from it.
- **Package**: check for updates, update, automatic updates (daily / weekly / monthly), switch LuCI to or away from Outline, uninstall or remove everything.

Changes preview on the settings page only and are kept with LuCI's **Save** / **Save & Apply**.

## Navbar

Navigation is now a row of floating pills along the top by default: the logo and hostname, the sections in the middle, and theme, search and logout on the right. Hover or click a section to see its pages. _Appearance › Navigation_ switches back to the sidebar; phones keep the drawer.

- The pills line up with the content column and move out only when they need the room; on narrow windows the sections drop to icons.
- The top of the page blurs behind the pills once you scroll.
- Sections that other apps add get a letter icon, so they stay apart from each other.

## Install in one line

```sh
wget -qO- https://raw.githubusercontent.com/tickcount/luci-theme-outline/master/install.sh | sh
```
