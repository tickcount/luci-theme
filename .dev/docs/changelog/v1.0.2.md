## Outline 1.0.2

Visual fixes and the Outline logo as the site icon.

### Fixes

- System › Mount Points: "Mounted file systems" is drawn below the Global Settings card again instead of inside one outer frame (the release build's minified card rule outranked the exception).
- Section tables: the first row under the column titles no longer rounds its top corners, so its hover fill sits flush under the header.
- Table rows: the hover fill stops at the row's divider instead of painting over it.
- Port status tooltips (Status › Overview): labels and the network name are readable on the dark bubble, LuCI's icons inside it are light, and the zone colour is a bare dot in both themes.
- Favicon, Apple touch icon and web-app icons show the Outline logo; the web manifest's icon paths resolve again.
