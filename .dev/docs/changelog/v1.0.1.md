## Outline 1.0.1

Viewport and layout fixes: no page scrolls sideways any more, on a phone or beside the expanded sidebar.

### Fixes

- Tables switch between stacked cards and a grid by the width they actually get, not the window's: a 768–1280px window beside the sidebar no longer scrolls the whole page sideways. The same applies inside dialogs.
- Stacked table rows: left-aligned cells, row titles on top, cells that never break mid-word, row action buttons that fit the card.
- Long unbroken values (keys, URLs) wrap instead of running off the screen; hidden tooltips no longer widen the page.
- Phone tab rows scroll the selected tab into view.
- Button groups and field + button pairs wrap on narrow screens (Local Time sync, Software filter).
- Status › Firewall: toolbar no longer overlaps the tabs; rule tables keep their padding and readable match badges.
- Network › Diagnostics: the empty output box is hidden until a command runs.
- System › Logs: filter bars wrap cleanly.
- Overview status cards, port status cards, nested sections and dynamic lists fit their rows on phones.
- Theme toggle shows the right icon from the first paint (no sun → moon flip).
